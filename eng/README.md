#### 1. What is Linera?

<figure><img src=".gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>

Linera is a Layer 1 built around **microchains**: each user can run a lightweight personal chain in parallel on the same validator set, targeting sub-second finality for real-time apps.
